# OpenArt b-roll prompts — 3 clips, ~5 s each

Three optional clips to drop into the final video for visual variety. Use OpenArt (openart.ai) → Video → Text-to-Video. The slides already carry the actual paper figures; these are purely cinematic sweetener.

**Shared style tokens** (keep consistent across clips): *scientific visualization, cinematic lighting, deep navy and warm amber accents (hex #0b0f17 bg, #ffb000 accent), 16:9 aspect ratio, 5 seconds, smooth slow motion.*

---

## Workflow in OpenArt Video

1. Open openart.ai → **Video** → **Text to Video**
2. Paste one prompt at a time
3. Set aspect ratio **16:9**
4. Model: whatever OpenArt's current default video model is (as of 2026 — try Kling or Veo variants if available)
5. Duration: as noted per clip (5 s / 3 s / 8 s)
6. Download MP4 → drop into Descript / iMovie timeline

## If OpenArt output quality is poor

- Fall back to **stock-footage** search for the same shots: Pexels or Pixabay has free "cell biology microscope" clips. Those will be more clinical-looking but accurate.
- Or **skip the b-roll entirely**: slide 2 + narration alone is enough. The data figures (slides 6-7) are the real stars.
